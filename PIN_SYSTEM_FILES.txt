🗄️ DATABASE
================================================================================

migrations/add-pins-and-kudi-sms.sql
├─ Creates 'pins' table
│  ├─ id (primary key)
│  ├─ business_id (foreign key)
│  ├─ pin_hash (bcrypt encrypted)
│  ├─ purpose (bank_account | withdrawal)
│  ├─ metadata (JSON)
│  ├─ expires_at (10 minutes)
│  └─ created_at
│
├─ Creates 'kudi_sms_balance' table
│  ├─ id (primary key)
│  ├─ balance (numeric)
│  ├─ last_updated
│  └─ created_at
│
└─ Creates 'kudi_sms_logs' table
   ├─ id (primary key)
   ├─ business_id (foreign key)
   ├─ phone_number
   ├─ message
   ├─ purpose
   ├─ kudi_message_id
   ├─ status (sent | failed | bounced)
   ├─ error_code
   ├─ error_message
   ├─ metadata
   └─ created_at

================================================================================
🔌 BACKEND - API ROUTES
================================================================================

app/api/pins/request/route.ts
├─ Endpoint: POST /api/pins/request
├─ Purpose: Generate PIN & send SMS
├─ Auth: Required (business owner)
├─ Input: { purpose, metadata }
└─ Output: { success, pinId }

app/api/pins/verify/route.ts
├─ Endpoint: POST /api/pins/verify
├─ Purpose: Verify PIN & execute action
├─ Auth: Required (business owner)
├─ Input: { pinId, pin }
└─ Output: { success, purpose }

app/api/kudi-sms/balance/route.ts
├─ Endpoint: GET /api/kudi-sms/balance
├─ Purpose: Check SMS balance
├─ Auth: Optional
├─ Output: { balance, lastUpdated, formattedBalance }
└─ Note: Public endpoint

app/api/kudi-sms/logs/route.ts
├─ Endpoint: GET /api/kudi-sms/logs
├─ Purpose: View SMS logs
├─ Auth: Required (business owner)
├─ Query: ?limit=50&offset=0&purpose=bank_account
└─ Output: { logs, total, limit, offset, hasMore }
